# natural-selection

Where [ForkedEvolution](https://github.com/ForkedEvolution) decides what gets
forked.

Every fork starts as a proposal here, is debated here, and is admitted or
rejected here. The [Decrees](DECREES.md) govern the whole process. They exist
so the experiment never turns into harassment of the people who wrote the code
we build on.

## Proposing a fork

1. Read the [Decrees](DECREES.md).
2. Open an issue using the **Fork proposal** form.
3. Discuss the proposal: license, value, naming, who will steward it.
4. An org member labels it:
   - `needs-steward`: the proposal is viable but nobody has volunteered to
     maintain the fork.
   - `admitted`: a steward is named and no Decree-based objection is open.
     The fork repo gets created, with [the banner](templates/BANNER.md) at the
     top of its README.
   - `rejected`: the issue is closed and locked, with the reason given.

Proposals describe what the fork adds. They never argue about upstream's
decision (Decree II).

## Upstream maintainers

If a project you maintain is mentioned here and something bothers you (a
name, a mention, anything), open an issue with the **Upstream request** form.
We act on it without argument (Decree X).

## Amending the Decrees

The Decrees change by pull request to `DECREES.md`, never by precedent or
chat agreement. A decree that isn't written here doesn't exist.
